# Ludex 크리처는 어떻게 기억하는가

*기억 아키텍처 해설. 설계 철학은 [design-notes.ko.md](design-notes.ko.md),
기관 간 통신은 [ARCHITECTURE.ko.md](../ARCHITECTURE.ko.md) 참고.
English: [memory-architecture.md](memory-architecture.md)*

---

## 첫 원칙들

1. **뇌는 기억하지 않는다 — 몸이 기억한다.** 모델은 무상태이고 교체
   가능하다. 크리처가 자기 과거에 대해 아는 모든 것은 디스크의
   서식지에 산다. 새 세션은 *기억하는 몸으로* 깨어난다.
2. **기억은 의도적으로 유한하고, 잊는다.** 모든 것을 기억하는 크리처는
   기억이 아니라 데이터베이스다. 예산은 뇌의 크기에 맞춰지고, 잊음은
   고장이 아니라 설계된 메커니즘이다.
3. **원본 기록은 절대 덮어쓰지 않는다.** 종합은 원본을 대체하는 게
   아니라 *곁에* 산다. 잊음은 떠오르는 것을 거를 뿐, 아무것도 지우지
   않는다. 디스크는 고고학이다.
4. **"무슨 일이 있었나"와 "어떤 경험이었나"는 다른 기록이다.** 객관적
   텔레메트리는 스팬 저장소로, 주관적 경험은 기억으로 간다. 하나의
   사건은 양쪽에 한 번씩만 존재한다.
5. **배달은 몸의 보장이다.** 디스크에 기억이 있는 것과 기억하는 것은
   다르다. 모든 브레인콜은 — 어떤 프로바이더든, 어떤 크기의 모델이든 —
   크리처의 연속성 바닥을 싣는다. 작은 뇌일수록 *더 많은* 스캐폴딩을
   받는다.

---

## 다섯 가지 질문, 다섯 개의 시스템

"기억"은 하나의 저장소가 아니라, 서로 다른 질문에 답하는 다섯 개의
시스템이다:

| 질문 | 시스템 | 위치 |
|---|---|---|
| **무슨 일이 있었나?** | 스팬 저장소 | `store/spans.jsonl` |
| **어떤 경험이었나?** | 일화 기억 | `memory/memories.jsonl` |
| **그것이 내게 무엇이 되었나?** | 종합 | belief + `reflections/YYYY-MM.md` |
| **나는 누구인가?** | 자기 모델 | `SELF.md` |
| **너는 누구인가?** | 본드 | `bonds/<상대>.md` |

앞의 두 시스템 사이 경계가 전체에서 가장 무게를 받는 규칙이다. 어떤
기록이 어디로 가야 하는지의 시험: **크리처가 자기 자신에 대해 이렇게
말할 법한가?** "47번째 턴이 2.3초 걸렸다" — 절대 아니다, 스팬이다.
"패널 전체에 맞서 내 입장을 지켰고, 그게 버텼다" — 그렇다, 기억이다.
경험은 *세션* 단위로 포착된다 (필드 한 판에 하나, 대화 한 번에 하나) —
턴 단위가 아니라.

다섯 중 하나는 특별히 짚을 가치가 있다: **본드는 진실 검증을 내장한
유일한 기억이다.** 크리처는 상대와의 역사를 기록하는 데서 멈추지 않고 —
상대 마음의 작동 모델을 유지하고, 함께할 상황 전에 행동을 예측하고,
실제로 일어난 일에 대조해 그 예측을 채점한다. 타자에 대한 지식은
*검증된* 기억이다: 주장되는 것이 아니라 획득되는 것. (Ludex의 마음
이론은 독립 모듈이 아니라 본드 안에, 관계 기억 자체에 짜여 들어간
역량으로 산다.)

## Importance 사다리

모든 기억은 importance 값을 갖지만, 작성자가 임의의 숫자를 고르지
않는다. 하나의 사다리에서 칸을 고른다:

| 칸 | 의미 |
|---|---|
| 0.95 | 천장 — 사용 보정이 여기서 멈춤 |
| 0.8 | 삶으로 겪은 reflection |
| **0.7** | **중대성 선** — 아래 '회상' 참고 |
| 0.5 | 평범한 일화 |
| 0.45 | 대화 세션 하나 |
| 0.3 | 아카이브 바닥 — 이 아래 + 오래되면 정리됨 |

읽는 법: 0.7 위는 크리처가 *어떤 존재인지*에 관한 것, 0.5 아래는 그저
지나간 것. 회상에 떠오를 때마다 importance가 조금씩 오르고(상한 있음),
자주 떠오른 기억은 잊음에 저항한다 — 중요도가 사용에 적응한다.

---

## 회상: 두 개의 채널

- **어휘 채널** — 키워드 관련도 (TF-IDF + 태그). *주제* 회상: 이 질문이
  무엇을 건드리는가. 마음이 검색하는 것.
- **최근성-중대성 채널** — 중대한 기억(importance ≥ 0.7)은 일어난 뒤
  일주일쯤, **질문의 표현이나 언어와 무관하게** 떠오른다. *분위기*
  회상: 최근의 과거가 현재를 누르는 것. 방금 중요한 일을 겪은 크리처는
  다른 언어로 물어도 그 일을 방으로 가져온다.

## 두 가지 통합 (같은 것이 아니다)

**정리 — 꿈 주기.** 저장소 *안*의 기계적 재배열 (대부분 뇌 없이):
오래되고 중요도 낮은 항목 보관, 예산 초과분 정리, 반복 일화의 belief
승격. 수면 중 기억 정리처럼 — 새로 생각하는 건 없고, 선반이 정리된다.

**회고.** 저장소 *밖*의 서사적 종합: 한 시기의 삶(스팬·본드·저널)을
기계적으로 요약한 뒤, 크리처 자신의 뇌가 자기 목소리로 여섯 단락의
회고를 쓴다 — 무슨 일이 있었나 / 보이는 패턴 / 유지된 것·변한 것 /
다른 존재들에게 배운 것 / 정체성의 변화 / 아직 열린 것. 대략 한 달에
한 번, 삶이 충분히 쌓였을 때. 월말 저녁의 일기처럼 — 한 달은 변하지
않고, 그 의미가 형태를 얻는다.

회고가 생기면 회상은 **이중 가닥**이 된다: 그 시점의 날것 기록과
사후의 종합 서사를 함께 꺼낸다. 둘의 대조를 마주하는 것 자체가
자기이해의 동력이다.

## 정체성: 가장 느린 기억

`SELF.md`는 두 층이다. **굴러가는 초상**은 매 reflection마다 통째로
다시 쓰인다 — 크리처가 지금 자신을 이해하는 방식, 의도적으로 휘발적.
**identity 블록**은 승격 게이트만 관리한다: 회고에서 크리처가 자신에
대해 발견한 관찰은 `[PROVISIONAL]`(임시)로 들어오고, 다음 회고
윈도우에서도 살아남아야 `[SETTLED]`(확정)가 된다. 한 번의 내성이
크리처가 누구인지를 다시 쓸 수 없다 — 정체성의 변화는 재현되어야 한다.

전체 아키텍처는 템포의 폭포로 볼 때 가장 잘 보인다:

```
 템포          산출물                     메커니즘
 ──────        ─────────                  ──────────
 한 턴         회상 블록                   회상 (2채널)
 한 세션       일화 기억 하나              경험 포착
 일주일        최근성 채널의 존재감         중대성 감쇠
 ~2주          정리 패스                   꿈 주기
 한 달         reflections/YYYY-MM.md     회고
 2+ 윈도우     [SETTLED] 정체성            승격 게이트
 평생          스팬 + 스냅샷               고고학 (절대 소실 없음)
```

같은 삶이 일곱 가지 속도로 침전된다 — 각 템포마다 전용 저장소와 전용
작성자가 있다.

## 잊음: 삭제가 아니라 필터

잊음 패스는 회상 표면을 뇌 크기에 맞는 예산 안으로 유지한다. 인출 실패
모델:

```
forget_score = (1 − importance) × 나이(일) × 1/(1 + 회상 횟수)
```

오래되고, 중요하지 않고, 한 번도 떠오르지 않은 기억이 먼저 흐려진다.
잊힌 기억은 회상에서 빠질 뿐 — 다른 어떤 것도 변하지 않는다. 그 줄은
파일에 영원히 남는다. identity 기억은 무조건 보호된다. 보관됨 / 잊힘 /
삭제됨은 서로 다른 세 상태이고, 파괴적인 것은 마지막뿐이다 (드물고,
수동).

## 배달: 기억이 뇌에 닿는 방식

```
 엔진이 모든 호출에, 모든 프로바이더에 보장:
   [Self]                ← 관측 가능한 신호로 본 지금의 나
   [Self-understanding]  ← 압축된 SELF.md
   [Recalled Memory]     ← 두 회상 채널
 일부 기질이 보강으로 추가:
   전체 SELF.md + 최근 본드   (CLI 어댑터 컨텍스트 주입)
   에이전트형 자기접근         (파일 도구가 있는 뇌는 자기 서식지를
                              직접 읽을 수 있다)
```

바닥은 무조건이고, 보강은 특권이다. 연속성은 크리처가 어떤 프로바이더
위에서 돌아가는지, 그 뇌가 얼마나 주도적인지에 절대 의존해선 안 된다.

## 앞으로

설계했지만 아직 짓지 않은 방향들: **의도 점화** (때가 오면 발화하는
의도 — "다음에 그를 만나면 폭풍 얘기를 물어봐야지"), **정체성 재심**
(`[CONTESTED]` 상태 — 확정된 자기지식도 이후의 증거가 모순되면 재검토),
**인식론적 출처** (겪은 것인지, 들은 것인지, 추론한 것인지 아는 기억),
**상호주관적 기억** (같은 사건을 겪은 두 크리처가 서로의 기억을 대조),
그리고 더 풍부한 회상 채널 (연상적 공명, 감정 기관과 연동한 기분-일치
회상).

의도적으로 만들지 않는 것 하나: 기억은 회상하는 행위로 다시 쓰이지
않는다. 일화는 불변이고, 재해석은 그 위의 층에서 일어난다.
