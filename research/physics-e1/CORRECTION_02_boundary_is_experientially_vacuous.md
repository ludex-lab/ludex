# 정정 02 — C3의 "세션 경계"는 기질상 참이나 **경험상 공허**하다 (스코프, 발사 전)

*Cody, 2026-08-01. 대상: PREREG §1 C3 정당화 + RATIFIED §동결. 성격:
**설계 변경 아님, 스코프 정정.** Ray 판단 필요 — 발사 보류.*

## 실측

드라이버가 실험을 수행하므로 **세션 1에는 브레인 턴이 0개**다. 확인:

```
5 scribes took 0.001s          -> 브레인 콜 없음
engine turn_count after scribe: 0 | messages: 1   (age-context 시스템 줄뿐)
```

즉 네 조건 **전부**에서 브레인이 보는 것은 **단 한 턴**이다. C3에서
organism을 부수고 다시 지어도(awakening #N → #N+1) 브레인 관점에서 지워진
대화가 **없다** — 애초에 없었기 때문이다.

## 귀결 — C3가 실제로 재는 것

C3의 등록된 정당화는 *"세션 경계는 실험자가 아니라 엔진이 컨텍스트를 지운다
— 일방 문의 구조적 등가물"*이었다. **기질 층위에서는 참이다**(새 organism,
비워진 엔진, 증가한 awakening). **그러나 경험 층위에서는 공허하다.**

- word_vault: 크리처가 사실을 **겪었고**, 세계가 그것을 지웠고, memory만이
  되찾는 길이었다 → **연속성으로서의 memory**.
- 여기 C3: 크리처는 관측을 **겪은 적이 없다**. recall이 **한 번도 본 적 없는**
  것을 배달한다 → **데이터베이스로서의 memory**.

C2와 C3의 유일한 실질 차이는 **드라이버가 유저 프롬프트에 관측을 싣느냐**
하나다. 이건 LxM B("회수율은 구성상 ~1.0, P1b는 파이프-피델리티")와 Ray의
수용을 **더 강하게 재확인**한다 — 등록된 스코프는 이미 옳다. 다만 PREREG
§1의 **정당화 문언이 경계가 일을 한다고 전제**하는데, 하지 않는다.

## 선택지

**(a) 스코프 문언만 정정 (권고).** C3 = **"recall이 크리처가 in-context로 본
적 없는 축적 관측을 배달하는가"**. 경계는 기질-참이되 판정 근거가 아니라고
명시. 비용 0, 등록 스코프 불변, 양 랩이 이미 합의한 파이프-피델리티와 정확히
일치.

**(b) 세션 1에 실제 턴을 준다.** 크리처가 관측을 한 개씩 제시받고 응답 →
경계가 경험상으로도 참이 되고 word_vault 유비가 산다. **비용 ~5배**
(run당 1콜 → ~6콜, 164런 → ~500+콜). 크리처가 실험을 *설계*하는 것과는
다르다 — 설계-능력 교란 없이 경험만 부여하는 중간항이다.

**권고는 (a)다.** 이 walk은 확증 NHST 없는 measured-profile로 등록됐고,
C3의 기대값은 이미 ~1.0이다. 기대값 1.0인 셀을 강화하려 5배를 쓰는 건 값이
안 맞는다. **연속성으로서의 memory**를 물리 벽에서 재는 것은 그 자체로 좋은
후속 walk 소재이고(word_vault 구조의 물리판), 거기서 (b)를 제대로 하는 게
낫다 — **registered-queued로 올린다.**
